# 关于本项目

XRobot 前身为 [qdu-rm-mcu](https://gitee.com/qsheeeeen/qdu-rm-mcu.git)，由 [@qsheeeeen](https://gitee.com/qsheeeeen) 于 2019 年 1 月 19 日创建，一直作为青岛大学 RoboMaster 未来战队的电控框架，也被多所高校和公司使用。XRobot 从基于 Keil MDK 的战车 MCU 代码发展为跨平台的嵌入式软件框架，目前覆盖嵌入式开发的完整流程。历经风风雨雨，XRobot2.0正式发布，希望与你一同前进。
