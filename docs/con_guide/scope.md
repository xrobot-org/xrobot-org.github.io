# 贡献范围

以下内容都属于有效贡献。

## 代码

- 明确的 bug fix
- 缺失功能补充
- 驱动适配
- 并发、状态机和超时行为修正
- 编译与构建修复

## 模块

- 新模块（编写方法见[编写模块](../proj_man/create_mod.md)）
- 模块加入官方源（见 xrobot-modules 的[添加模块 / Adding a Module](https://github.com/xrobot-org/xrobot-modules/blob/dev/README.md#添加模块--adding-a-module)）

## 文档

- API 说明修正
- 章节结构和目录整理
- 示例代码与实际行为对齐
- 中英文内容补齐
- 截图、路径和命令更新

## 测试与验证

- 单元测试补充
- 实机回归验证
- 性能回归结果补充
- 平台矩阵验证
- 最小复现工程或问题复现脚本
